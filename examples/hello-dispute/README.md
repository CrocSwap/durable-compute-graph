# DCG Hello Dispute

This example runs the revision-8 app-bound replay seam with the statically
linked `ByteSum` test kernel. It shows both a lying executor convicted and an
honest executor defeating a false challenge. The Rust integration tests submit
the real document, challenge, response, settlement, and close instructions to
an in-process Solana `ProgramTest` bank.

## Run both outcomes

Use Rust/Cargo from the checked-in toolchain and the retained PT2P bundle used
by the DCG integration tests. The bundle is generated by the Basanos compiler
and is not checked into this standalone repository.

```sh
BASANOS_PT2P_ROOT=/path/to/retained/pt2p python3 examples/hello-dispute/run.py
```

The directory must contain `base-routes.bin`, `base-geometry.bin`,
`base-payloads.bin`, and `program.bin`. `clause12-v4.bin` is optional; DCG
derives it from `program.bin` when it is absent. The runner builds into
`/private/tmp/basanos-dcg-hello-dispute-target` and runs each targeted ProgramTest case
with Cargo's locked dependency graph.

To run one outcome, append `--scenario liar` or `--scenario honest`. The script
prints a short ruling narrative and the matching ProgramTest pass/fail result;
the test assertions check the ruling and settlement account movements.

## What happens

The `liar` case commits a ByteSum output with prefix `[4, 5, 6]` where the bound
kernel requires `[1, 2, 3]`. The challenger opens the app-bound leaf. Tag 169 replays
the commitment, records the executor's loss with code 800, and tag 131 settles
the challenger win. Tag 172 closes the refuted document.

The `honest` case commits an output with prefix `[1, 2, 3]`, then challenges that correct output. The
fix-point leaves the challenge open in RESPOND. The executor stages its
committed witness with tag 183 and answers with tag 184; replay agrees and the
executor wins. Tag 131 returns the challenge bond to the executor.

This is a native ProgramTest mechanics demonstration. It is not an SBF image,
validator, network, production-app, or useful-model-quality result. The cases
reuse the existing ByteSum test manifest and retained PT2P template.

## Cleanup

After the run, move the generated Cargo target out of the active build path:

```sh
mv /private/tmp/basanos-dcg-hello-dispute-target /private/tmp/trash-hello-dispute
```
