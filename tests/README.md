# Test fixture and image map

Run repository tests offline with:

```sh
cargo test --locked --offline --profile fasttest --all-targets
```

The revision-8 suites, their SBF runner and their Basanos fixtures were removed
with revision 8 after v0.1.0-alpha (they are in that tag).

## Test files and required features/images

| Test file | Feature set | Image or fixture requirement |
| --- | --- | --- |
| `account_provenance_lint.rs` | default | Host-only; no image or external fixture. |
| `bytesum_sbf_lifecycle.rs` | `sbf-lifecycle-test` | ProgramTest against the `sbf-lifecycle-test` SBF image. |
| `commit_fold.rs` | default | Host-only; checked-in vectors. |
| `portable_goldens.rs` | default | Host-only; checked-in vectors. |
| `stateful_sbf_workload.rs` | `sbf-real-lifecycle-test` | ProgramTest against the `sbf-real-lifecycle-test` SBF image. |
| `stateful_v2_sbf_workload.rs` | `sbf-real-lifecycle-test` | ProgramTest against the `sbf-real-lifecycle-test` SBF image. |
| `stateful_v3_sbf_workload.rs` | `sbf-real-lifecycle-test` | ProgramTest against the `sbf-real-lifecycle-test` SBF image and retained resource data generated by the test. |
