# Test fixture and image map

Run repository tests offline with:

```sh
cargo test --locked --offline --profile fasttest --all-targets
```

The historical v7/rung-D tests (the former `legacy-basanos-fixtures`
feature) moved to Basanos with their fixtures (alpha plan R4, 2026-10-05). Revision-8 SBF suites use
[`scripts/run-rev8-sbf-suites.sh`](../scripts/run-rev8-sbf-suites.sh), which
builds the default, app-lifecycle, and unbound-form images in sequence and
fails before testing if a required base fixture is missing or malformed. If
the retained typed-decision K=10,240 fixture is absent, it records the five
typed K=10,240 probes as unverified, runs the plain-fixture probes, and exits
nonzero.

## `BASANOS_*` environment variables

Paths below are relative to the Basanos checkout at
`/Users/colkitt/sith/toys/crypto/basanos`. Variables absent from the environment
are optional unless marked required by the SBF runner. For fixture roots, the
directory must contain `base-routes.bin`, `base-geometry.bin`,
`base-payloads.bin`, and `program.bin`; `clause12-v4.bin` is read when present
or reconstructed by the test.

| Variable | Used by | Expected value or Basanos artifact |
| --- | --- | --- |
| `BASANOS_DCG_PREP_LONG` | `lifecycle_property_harness.rs` | Set to run 1,024 rather than 96 generated attempts; no fixture. |
| `BASANOS_DCG_PREP_SEED` | `lifecycle_property_harness.rs` | Integer seed for reproducing generated attempts; no fixture. |
| `BASANOS_DCG_V8_SBF` | `unified_v8_document.rs` | Set to `1` only with `BPF_OUT_DIR` pointing to the intended feature-built image. |
| `BASANOS_DCG_F47_DEFAULT_ROLE_ONLY` | `unified_v8_document.rs` | Presence restricts the Form-47 CU sample to its default role order; no fixture. |
| `BASANOS_DCG_F47_ONLY_K` | `unified_v8_document.rs` | `u8` option count for a focused Form-47 CU sample; no fixture. |
| `BASANOS_DCG_F47_PROBE_LIMIT` | `unified_v8_document.rs` | `u32` ProgramTest compute-unit budget for the Form-47 probe; no fixture. |
| `BASANOS_DCG_F47_RECEIPT` | `unified_v8_document.rs` | Optional output directory for Form-47 measurement JSON; no input fixture. |
| `BASANOS_DCG_F48_RECEIPT` | `unified_v8_document.rs` | Optional output directory for Form-48 measurement JSON; no input fixture. |
| `BASANOS_EXPECT_STORED_CHALLENGE_BUMP` | `unified_v8_document.rs` | Presence enables deliberate stored-bump corruption controls; no fixture. |

| `BASANOS_PT1X_FULL_E2E` | `unified_v8_document.rs` | Set to `1` to enable the full PT1X lifecycle case; requires the K=10,240 PT2P bundle selected with `BASANOS_PT2P_K10240_ROOT`. |
